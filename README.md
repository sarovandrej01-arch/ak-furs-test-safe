# AK Furs: программа анализа и история разработки

В этой копии сохранена история разработки Q1–Q4 и исправлений классификатора.
Исходные учебные файлы, рассчитанные ответы, тексты Q5 с данными и подробные
диагностические документы исключены из всех коммитов. Документы Q5 сохранены
только в исходном локальном проекте и передаются отдельно в закрытом порядке.

## Установка

Проверенная версия Python — 3.14.3. В корне проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip check
```

В Linux/macOS путь к интерпретатору окружения: `.venv/bin/python`.
Зависимости закреплены в requirements.txt; исторические версии этого файла
сохранены для оценки хода разработки.

## Данные и запуск

Получите исходники у работодателя и локально разместите в data/:
`01_crm_orders_export.csv`, `02_bank_statement_rub.csv`,
`03_catalog_prices_reference.xlsx`, `04_client_chats.zip`, `answers_template.json`.
Эта копия их не содержит и не загружает автоматически.

После активации окружения:

```powershell
python solve.py data/ > answers.json
python -m json.tool answers.json
python -m pytest -q
```

В PowerShell без активации используйте `.\.venv\Scripts\python.exe`
вместо python. Для перенаправления UTF-8 рекомендуется PowerShell 7.4+.
stdout содержит только JSON; диагностика идёт в stderr.
Можно передать другую папку данных. Интеграционные тесты требуют локальных
исходников; они не должны включаться в репозиторий вместе с результатами.

## Структура

- solve.py — единая команда расчёта;
- src/ — загрузчики, нормализация, CRM, банк, цены и чаты;
- tests/ — искусственные примеры и интеграционные проверки;
- docs/methods.md — методы без результатов учебного набора;
- docs/safe_repository.md — описание подготовки безопасной копии.

Содержание src/ и solve.py сохранено без изменения бизнес-логики.
В тестах исключены привязки к реальным именам, конкретному чату и
размерам исходных таблиц; функциональные сценарии сохранены.

answers.json, data/, reports/ и диагностические выгрузки исключены из Git.
Не добавляйте их принудительно. Для оценки результатов передавайте их
работодателю отдельно по согласованному закрытому каналу.
У копии нет remotes; старый origin не подключён.
