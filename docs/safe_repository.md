# Подготовка безопасной копии

Содержательные этапы разработки сохранены: 9 исходных коммитов.
Пустые после удаления данных коммиты оставлены как исторические этапы.
Затем добавлен отдельный коммит документации и защитных исключений.

Из всей истории исключены исходники, рассчитанные ответы, подробные
диагностические документы и тексты с результатами. README заменён безопасной
инструкцией. В тестах обезличены сообщения с реальными суммами, имя из
справочника, привязка к конкретному чату и размеры исходных таблиц.
Искусственные числовые примеры остаются для проверки алгоритмов.

Исходный локальный проект сохранён. Эта копия не связана ни с одним origin
и сама по себе не имеет внешней ссылки. Никакой публикации не выполнялось.
Очистка не удаляет данные из старого публичного репозитория и чужих копий.
Авторские имена и адреса электронной почты в метаданных истории сохранены.

Проверка: все 314 тестов очищенной копии прошли на внешнем локальном
наборе данных через отдельный тестовый стенд. Данные и временные копии
не размещались в этом репозитории. Файлы бизнес-логики совпадают с исходной
версией после нормализации переводов строк; изменены только данные тестовых
примеров и безопасная документация.
